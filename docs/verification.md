## 本地自动化与安全回归

本地浏览器用合成页面和会话，模拟页面请求在联网前被拦截到测试 HTML；不会向真实抖音发送作品、评论或上传文件。

- `go test ./...`：参数、路径边界、媒体类型/大小、私有文件、Cookie、回执与 MCP/REST。
- `DY_BROWSER_TESTS=1 go test -race ./... -count=1`：持久化资料保存/重启/清除、长期标签页请求取消回归，发布与网页交互的 Chrome 本地模拟测试。
- 发布：视频/多图上传与文案填写；准备不提交，确认一次，跨进程读取回执；文案、素材、会话变更拒绝；unknown 不重试。
- 互动：搜索及楼中楼引用；点赞、收藏、评论、子回复、评论赞；静态按钮提示文字；点踩折叠仍准确核验与撤销；平台追加验证会阻断。
- 富文本：@ 精确候选选择、平台表情、本地图片预览，包括平台清空文件选择框；候选查询替换旧预览，失败附件不串到下一次。
- 图文：独立 note-detail 的作品 ID 绑定、状态标识、评论面板及无 ID 的底部编辑器，拒绝目标变成另一作品后继续操作。
- 误发保护：账号、作品、评论、编辑器改变时不提交；旧 toast、输入框清空、计数变化不能证明新评论发出；提交前保存记录；回执写入失败不能重新使用旧操作。
- 登录清除：服务未打开浏览器时也清除已停止的专用资料；拒绝无标记、越界或仍锁定的资料目录。
- 后台标签页：修复 rod 的帧等待及鼠标/键盘未继承请求超时的问题；冻结 requestAnimationFrame 的模拟页仍可输入、单次可信点击、截取二维码；遮挡控件按请求期限退出，不穿透点击。
- MCP：新版 2026-07-28 发现协议、2025-11-25 初始化兼容、17 个工具、QR 正确编码、无短信工具。
- HTTP：全部新旧业务路由鉴权、Host/Origin/跨站防护、JSON 类型与未知字段拒绝、串行执行和取消处理。
- `go vet ./...`、`go mod verify`、`git diff --check`；macOS arm64 与无 CGO 的 Linux amd64/arm64 构建。
- `govulncheck ./...`：本次数据库检查未发现已知漏洞；不排除未知问题、站点自身问题或浏览器/操作系统漏洞。

## 尚未覆盖与使用边界

- 创作者中心真实视频/图文作品的最终发布、审核及作品 ID。既有实现通过本地模拟，不应写成真实发布已验收。
- 图文上的所有富文本回复组合、每个筛选选项组合、长评论树、删除/封禁作品、不同账号实验页面与网络中断路径，未逐一实测。
- Docker 镜像、容器 Chromium/沙箱/挂载权限和 Linux 真实浏览器流程；开发主机没有 Docker。交叉编译不等于运行验收。
- 平台可能再次要求手动验证或限制功能；保持登录不等于免验证。
- 暂不实现私信、关注、转发、付费/交易、删除历史内容、无限翻页、批量互动或验证码绕过。

## 依赖兼容性

直接依赖沿用本次已核对的稳定版本，详见主 README。实际尝试升级不兼容的传递依赖后保留：

- `fetchup v0.2.3`：v0.5.3 的 API 与当前 rod 不兼容；本项目不走浏览器自动下载流程。
- `got v0.41.0`：v0.43.0 已移除当前 rod 所需的 lib/lcs。

不把“所有包升级至最高版本”当作正确性或安全性证明；不兼容升级不强行合入。浏览器只使用本地显式可执行文件，不启用 leakless 辅助二进制。
