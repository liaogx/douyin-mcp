## 本地自动化与安全回归

### 2026-09-08：默认后台窗口与验证接管

增加默认开启的 `--background`：桌面 Chrome 的专用窗口从创建时就最小化，使用页面焦点模拟保持输入和页面更新活跃，普通操作不激活桌面窗口。检测到登录/安全验证后关闭焦点模拟、恢复原窗口；后续请求先检查待验证页面，确认解除后回到后台。验证页在准备失败时仍保留，关闭的目标经浏览器确认后解除等待，不自动发送或重放操作。

新增独立合成回归：后台新页面保持最小化；在同一文档内准备评论、模拟验证阻断、模拟人工完成、恢复后台、评论后点赞；动作、编辑器、目标 ID 不变，验证按钮没有被程序操作。另一测试覆盖图片准备时触发验证和手动关闭窗口。图文布局测试延迟挂载互动控件，确认程序等待真实控件稳定后才返回详情，不误把刚出现的页面外壳视为就绪。

本机真实账号已通过后台登录状态检查、固定关键词与五项组合筛选、少量新帖的文字评论及成功后点赞。评论依据同页新增的本人评论确认，点赞取得业务成功响应；未逐步重新打开网页。账号的既有专用资料仍可用，本次没有触发新的真实安全验证，因此弹窗接管路径的本次验收依据是合成页面测试，而不是声称真实验证已再次发生。具体账号、关键词、帖子和操作记录只保存在运行目录，不放入公开仓库。

复现本地后台回归：`DY_BROWSER_TESTS=1 DY_BACKGROUND_BROWSER_TESTS=1 go test -race ./... -count=1`。所有平台请求均由测试夹具在联网前拦截；模拟验证会短暂恢复测试自己的窗口，不操作真实账号。常规测试、原无头合成回归、后台合成回归、`go vet`、模块完整性检查和 macOS 本机构建分别验收；不代表 Linux 窗口管理器或无桌面容器已测试。

### 2026-09-08：同页响应确认与人工验证接管

新增单次提交的被动响应适配：普通顶层文字评论核对请求对象/正文与响应中的业务状态、评论 ID、作者；作品点赞/收藏核对本次期望值、业务成功响应及当前控件状态。不会额外发送写请求或为每步打开新页面；原始响应、签名及请求头不写入回执或日志。HTTP 200、乐观按钮变色不能独立判定成功。验证提示保留并尝试激活对应专用窗口，仍由用户手动处理。

该响应格式适配须通过后续获得授权的真实操作继续验证；本次不新增真实评论测试，也不把模拟 HTTP 响应当成真实平台承诺。既往仅依据页面状态的测试不能证明点赞/收藏已由服务端持久保存。没有可靠响应时宁可 `unknown`，不以额外点击、重发或取消来验证。

新增回归覆盖：HTTP 200 缺少业务字段/业务失败；响应中的作品、正文、作者或评论 ID 不符；请求来源、方法、重复参数与目标状态不符；只变色无响应；正常评论后点赞只创建一个详情页；失败回执重放不再次操作；验证控件不自动点击、页面保留、监听器释放与焦点请求取消。

本地验收通过：常规全量测试、启用 Chrome 合成页面的全量 race 测试、`go vet`、模块完整性检查与本机构建。没有新依赖；未用真实账号额外发送评论或互动来完成这些测试。

本地浏览器用合成页面和会话，模拟页面请求在联网前被拦截到测试 HTML；不会向真实抖音发送作品、评论或上传文件。

- `go test ./...`：参数、路径边界、媒体类型/大小、私有文件、Cookie、回执与 MCP/REST。
- `DY_BROWSER_TESTS=1 go test -race ./... -count=1`：持久化资料保存/重启/清除、长期标签页请求取消回归，发布与网页交互的 Chrome 本地模拟测试。
- 发布：视频/多图上传与文案填写；准备不提交，确认一次，跨进程读取回执；文案、素材、会话变更拒绝；unknown 不重试。
- 互动：搜索及楼中楼引用；点赞、收藏、评论、子回复、评论赞；静态按钮提示文字；点踩折叠仍准确核验与撤销；平台追加验证会阻断。
- 搜索回归：必须经搜索输入框和按钮触发；识别“服务出现异常”等页面错误，最多恢复一次并重设全部原筛选；筛选结果延迟报错时不继续选下一项；人工验证后恢复不再次点击搜索；菜单在初始化/筛选点击后关闭能重新展开；返回结果前后核对全套筛选状态；排除带作品链接的“相关搜索”推荐卡。
- 富文本：@ 精确候选选择、平台表情、本地图片预览，包括平台清空文件选择框；候选查询替换旧预览，失败附件不串到下一次。
- 图文：独立 note-detail 的作品 ID 绑定、状态标识、评论面板及无 ID 的底部编辑器，拒绝目标变成另一作品后继续操作。
- 误发保护：账号、作品、评论、编辑器改变时不提交；旧 toast、输入框清空、计数变化不能证明新评论发出；提交前保存记录；回执写入失败不能重新使用旧操作。
- 登录清除：服务未打开浏览器时也清除已停止的专用资料；拒绝无标记、越界或仍锁定的资料目录。
- 后台标签页：修复 rod 的帧等待及鼠标/键盘未继承请求超时的问题；冻结 requestAnimationFrame 的模拟页仍可输入、单次可信点击、截取二维码；遮挡控件按请求期限退出，不穿透点击。
- MCP：新版 2026-07-28 发现协议、2025-11-25 初始化兼容、17 个工具、QR 正确编码、无短信工具。
- HTTP：全部新旧业务路由鉴权、Host/Origin/跨站防护、JSON 类型与未知字段拒绝、串行执行和取消处理。
- `go vet ./...`、`go mod verify`、`git diff --check`；macOS arm64 与无 CGO 的 Linux amd64/arm64 构建。
- `govulncheck ./...`：本次数据库检查未发现已知漏洞；不排除未知问题、站点自身问题或浏览器/操作系统漏洞。

## 尚未覆盖与使用边界

- 创作者中心真实视频/图文作品的最终发布、审核及作品 ID。既有实现通过本地模拟，不应写成真实发布已验收。
- 图文上的所有富文本回复组合、每个筛选选项组合、长评论树、删除/封禁作品、不同账号实验页面与网络中断路径，未逐一实测。
- 部分关键词选择“一天内”后，真实页面仍可能显示“服务出现异常”；点击搜索可恢复默认结果，但会清空筛选。这不是符合原条件的成功搜索；程序只能检测、有限恢复和明确报错，不能保证平台接受所有组合。
- Docker 镜像、容器 Chromium/沙箱/挂载权限和 Linux 真实浏览器流程；开发主机没有 Docker。交叉编译不等于运行验收。
- 平台可能再次要求手动验证或限制功能；保持登录不等于免验证。
- 暂不实现私信、关注、转发、付费/交易、删除历史内容、无限翻页、批量互动或验证码绕过。
